# v1.12.3 Release Notes

- Replaced operating-system-dependent navigation glyphs with six consistent inline vector icons.

- Normalized heading, navigation, and KPI weights for consistent rendering across browsers.
- Preserved responsive two-column mobile navigation, keyboard focus, reduced motion, and accessible text labels.
